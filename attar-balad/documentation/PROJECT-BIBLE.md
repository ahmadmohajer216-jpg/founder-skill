# سند جامع پروژهٔ عطار بلد

**نسخه:** ۵٫۰ · **تاریخ:** نوامبر ۲۰۲۶ · **دامنه:** فروشگاه گیاهان دارویی عطار بلد
**وضعیت:** نسخهٔ استاتیک کامل و قابل بازبینی؛ قالب وردپرس/ووکامرس آمادهٔ استقرار.

این سند کار پنج فاز را در یک مرجع جمع می‌کند: از معماری و دیزاین سیستم تا فروشگاه
استاتیک، هویت بصری، جزیرهٔ سه‌بعدی و پیاده‌سازی وردپرس.

---

## ۱. خلاصهٔ اجرایی

عطار بلد یک فروشگاه راست‌به‌چپ فارسی برای گیاهان خشک، ادویه، دمنوش و عرقیات ایرانی
است. مخاطب اصلی زن ۳۰ تا ۵۵ سالهٔ ایرانی است که با موبایل خرید می‌کند و می‌خواهد در
یک لمس به دستهٔ مورد نظرش برسد. لحن برند «عطاری سلطنتی» است: کرم گرم، سبز جنگلی،
طلای کهنه و قوس ایرانی — گران و آرام، نه ارزان و شلوغ.

سه اصل غیرقابل‌مصالحه:

1. **اصالت قابل اثبات:** هر محصول با تصویر تأییدشده، منبع روشن و شناسنامهٔ گیاه.
2. **سرعت و سادگی:** بدون build، بدون CDN تصویر، بدون انیمیشن پنهان‌کنندهٔ محتوا.
3. **یک منبع حقیقت:** توکن‌های دیزاین، کاتالوگ محصول و استاندارد تصویر در یک جا.

## ۲. معماری فنی

| لایه | انتخاب | دلیل |
|---|---|---|
| فروشگاه مرجع | HTML/CSS/JS خالص، بدون build | بازبینی سریع، قابل اجرا در هر محیط، مرجع رفتاری وردپرس |
| دیزاین سیستم | `tokens.css` + `components.css` + `site.css` | هیچ مقدار خام رنگی در اجزا نوشته نمی‌شود |
| دادهٔ نمایشی | `assets/js/data.js` (۴۹ محصول، ۶ دسته، ۶ مقاله) | تولیدشده از `image-library/PRODUCT-DATABASE/products.json` |
| حالت کاربر | `localStorage` (`ab_cart_v1`، `ab_wish_v1`، `ab_orders_v1`، `ab_user_v1`) | سبد و سفارش بدون سرور در فاز نمایشی |
| ماژول سه‌بعدی | وب‌کامپوننت `<attar-3d-viewer>` در Shadow DOM | جزیرهٔ ایزوله، بدون تداخل با اسکریپت‌های صفحه |
| فروشگاه واقعی | WordPress + WooCommerce + Child Theme + افزونهٔ اختصاصی | مدیریت محتوا، پرداخت و ارسال در فاز بعد |

جریان درخواست در نسخهٔ استاتیک:

```
مرورگر → index.html → shell.js (هدر/فوتر/سبد کشویی) → pages.js (رفتار صفحه)
                     → store.js (سبد، علاقه‌مندی، سفارش، کارت محصول)
                     → viewer3d.js (جزیرهٔ سه‌بعدی، فقط هنگام کلیک)
```

## ۳. دیزاین سیستم

- **رنگ:** سبز `#14532d` (اصلی)، سبز تیره `#0e3d21`، کرم `#f7f3e8`، طلا `#c5a45b`،
  مرکب `#292d27`. رنگ‌های مشتق (خط، سطح، هشدار) فقط از همین پالت ساخته می‌شوند.
- **تایپ:** Estedad برای تیتر، Vazirmatn برای متن؛ هر دو self-host در `assets/fonts`.
- **مقیاس فاصله:** ۴ تا ۹۶ پیکسل روی گام ۴ (`--ab-sp-1..9`).
- **شکل:** دکمهٔ قرصی، کارت ۱۶ تا ۲۴ پیکسل، و **کاشی قوس‌دار** به‌عنوان شکل امضای برند.
- **حرکت:** یک زبان easing و سه مدت (۱۶۰/۲۲۰/۳۲۰ms)؛ `prefers-reduced-motion` رعایت می‌شود.
- **قاعدهٔ کنتراست:** متن طلایی فقط روی مرکب یا سبز تیره؛ متن بدنه روی کرم با کنتراست
  حداقل ۴٫۵:۱.

## ۴. نقشهٔ اطلاعات

```
خانه
├── فروشگاه (فیلتر دسته/قیمت/موجودی، مرتب‌سازی، جست‌وجو)
│   └── محصول (گالری، اندازه، شناسنامهٔ گیاه، محصولات مرتبط)
│       └── سبد → تسویه → تأیید سفارش → پیگیری
├── گیاهان دارویی / دمنوش‌ها (میان‌بر دسته)
├── تاریخ طب ایران (خط زمانی شش دوره + نمای سه‌بعدی)
├── مجله → مقاله
├── باشگاه مشتریان
├── درباره ما / تماس / سؤالات متداول
└── حقوقی: قوانین، حریم خصوصی، ارسال، بازگشت، ۴۰۴
```

مسیر خرید: **کشف → مقایسه → افزودن → سبد → تسویه → تأیید → پیگیری**. هر مرحله در
نسخهٔ استاتیک با `localStorage` کار می‌کند و در وردپرس به سبد و پرداخت ووکامرس وصل
می‌شود.

## ۵. مدل داده

| موجودیت | فیلدهای کلیدی |
|---|---|
| محصول | `id`، `fa`، `en`، `botanical`، `cat`، `price`، `sizes[]`، `stock`، `rating`، `tags[]`، `img`، `origin`، `part`، `use`، `storage`، `warn` |
| دسته | `id`، `name`، `en`، `icon`، `blurb`، `count` |
| مقاله | `id`، `title`، `excerpt`، `body`، `source`، `date` |
| شناسنامهٔ گیاه | `product_id`، نام علمی، خاستگاه، بخش مصرفی، روش مصرف، نگهداری، هشدارها |
| سفارش (نمایشی) | `code`، اقلام، مبلغ، روش ارسال، روش پرداخت، نشانی، وضعیت |

قواعد: SKU هر محصول در ووکامرس همان `id` کاتالوگ است؛ ایمپورت دوباره به‌روزرسانی
می‌کند و رکورد تکراری نمی‌سازد. قیمت پایه = اندازهٔ اول کاتالوگ.

## ۶. هویت بصری و تصویر

- **نشان:** تاج + شاخهٔ گیاهی + قوس ایرانی در `assets/brand/logo-mark.svg`؛
  فاوآیکن `assets/brand/favicon.svg`.
- **پالت رسمی برند:** سبز جنگلی `#13291C`، طلای سلطنتی `#D8B15C`، طلای کهنه
  `#B38B3C`، کرم `#F5E9D2` (هم‌خانوادهٔ توکن‌های سایت).
- **استاندارد تصویر محصول:** فقط گیاه خشک و طبیعی در کاسهٔ مسی؛ قاب، رنگ، نور و متن
  ثابت است و فقط گیاه عوض می‌شود. مرجع بصری: عطاری‌های «مشکستان» و «عطارک».
- **قاعدهٔ متن:** همهٔ متن فارسی، قیمت و نام محصول متن واقعی HTML است، نه داخل تصویر.
- ده فصل پرامپت آمادهٔ اجرا (لوگو، قهرمان سینمایی، تصاویر دسته، عکاسی محصول، پانوراما،
  تحریریه، باغ، نقش‌مایه، بنر، بسته‌بندی) در `documentation/BRAND-IDENTITY.md`.

## ۷. جزیرهٔ سه‌بعدی

`<attar-3d-viewer>` بر اساس سند «ماژول سه‌بعدی ووکامرس» ساخته شده، با یک تفاوت آگاهانه:
به‌جای Three.js/WebGL از رندر CSS 3D استفاده می‌کند. دلیل: هدف سند حفظ LCP و INP است و
CSS 3D هیچ بایتی دانلود نمی‌کند، GPU را درگیر نمی‌کند و با جی‌کوئری ووکامرس تداخل ندارد.

- شش دورهٔ تاریخ طب روی یک استوانهٔ شش‌ضلعی؛ چرخش فقط با تعامل (کلیک، کشیدن، کلید).
- موتور قابلیت‌سنجی: `saveData`، `effectiveType` 2G یا نبود `preserve-3d` → نمای
  دوبعدی قابل‌اسکرول.
- همگام دوطرفه با خط زمانی صفحه؛ برچسب زنده برای screen reader.
- جزئیات فنی و چک‌لیست پذیرش: `documentation/PHASE-5-3D-ISLAND.md`.

## ۸. وردپرس و ووکامرس

| نیاز | پیاده‌سازی |
|---|---|
| قالب | `attar-balad-child` روی Twenty Twenty-Five، با `theme.json` و نگاشت توکن‌ها |
| صفحه‌سازی | Gutenberg + شورت‌کدهای ووکامرس (بدون Elementor) |
| واحد پول | `IRT` با نماد «تومان» و صفر اعشار |
| شناسنامهٔ گیاه | جدول `wp_ab_plants` + متاباکس + نمایش در صفحهٔ محصول |
| ایمپورت کاتالوگ | `wp attar import` — ۴۹ محصول، ۶ دسته، تکرارپذیر |
| هویت بصری | همان `logo-mark.svg` و توکن‌های فاز ۲ در پوشهٔ قالب |

قاعدهٔ طلایی: قالب فرزند هیچ رنگ خامی ندارد؛ همه از `var(--ab-*)` می‌آید تا یک تغییر
توکن، کل سایت و ووکامرس را هم‌زمان به‌روز کند.

## ۹. دسترس‌پذیری، کارایی، سئو

- **a11y:** `dir="rtl"`، `lang="fa"`، یک `h1` در هر صفحه، skip link، `aria-label` روی
  کنترل‌های آیکونی، تب‌های `role="tab"` با `aria-selected`، فوکوس واضح، کنتراست AA.
- **کارایی:** بدون فونت CDN، تصاویر WebP، بدون انیمیشن ورودی که محتوا را پنهان کند،
  بدون اسکریپت خارجی. جزیرهٔ سه‌بعدی فقط پس از کلیک فعال می‌شود.
- **سئو:** عنوان و توضیح یکتا، `og:` برای اشتراک‌گذاری، دادهٔ ساختاریافته در صفحهٔ
  محصول، ساختار عنوان منطقی، آدرس‌های قابل اشتراک (`?id=`، `?cat=`، `?q=`).
