# فاز ۴ – نصب وردپرس و ووکامرس، قالب فرزند و اسکلت افزونهٔ اختصاصی

**تاریخ:** ۲۰۲۶/۱۱/۲۲ · **وضعیت:** اسکلت آماده و اجراشده
**مرجع:** `documentation/PHASE-1-ARCHITECTURE.md` (بخش ۲ – معماری) و `documentation/PHASE-3-UI.md` (مرجع رفتاری)

## ۱. هدف مرحله

طبق برنامهٔ فاز ۱: «نصب WP/Woo + Child Theme + افزونهٔ اختصاصی (اسکلت)» با معیار
پذیرش «سایت بالا می‌آید، محصول نمونه نمایش داده می‌شود». این فاز نمونهٔ استاتیک فاز ۳
را حذف نمی‌کند؛ آن مرجع رفتاری می‌ماند و این نسخه، پیاده‌سازی واقعی روی وردپرس است.

## ۲. خروجی این مرحله

| مورد | وضعیت |
|---|---|
| وردپرس ۷ + ووکامرس ۱۱ روی MariaDB با `utf8mb4` | بالا می‌آید |
| قالب فرزند `attar-balad-child` روی Twenty Twenty-Five | فعال |
| افزونهٔ اختصاصی `attar-balad-core` | فعال |
| ایمپورت ۴۹ محصول، ۶ دسته، ۶ تصویر از کاتالوگ فاز ۳ | انجام‌شده و تکرارپذیر |
| واحد پول تومان (IRT) و RTL فارسی | فعال |
| شناسنامهٔ گیاه روی صفحهٔ محصول | نمایش داده می‌شود |

## ۳. فایل‌های این مرحله

```
attar-balad/wp/
└── wp-content/
    ├── themes/attar-balad-child/
    │   ├── style.css                 ← سرصفحهٔ قالب (Template: twentytwentyfive)
    │   ├── theme.json                ← پالت، فونت، مقیاس فاصله و تیتر به‌صورت preset
    │   ├── functions.php             ← صف‌بندی توکن‌ها/اجزا/نگاشت، پشتیبانی ووکامرس
    │   ├── assets/css/
    │   │   ├── tokens.css            ← همان توکن‌های فاز ۲ (بدون تغییر)
    │   │   ├── components.css        ← همان اجزای ab- فاز ۲ (بدون تغییر)
    │   │   └── theme.css             ← نگاشت دیزاین سیستم به وردپرس و ووکامرس
    │   ├── assets/fonts/             ← Vazirmatn و Estedad (self-host)
    │   ├── assets/img/               ← تصاویر محصول (نسخهٔ WebP فاز ۳)
    │   └── templates/front-page.html ← صفحهٔ اصلی با بلاک‌های Gutenberg
    └── plugins/attar-balad-core/
        ├── attar-balad-core.php
        └── includes/
            ├── class-plants.php      ← جدول wp_ab_plants + متاباکس + نمایش
            ├── class-currency.php    ← ثبت IRT (تومان)
            └── class-import.php      ← دستور `wp attar import`
```

سرویس‌های اجرا (`db`, `wp`, `wp-setup`) در محیط توسعهٔ Base44 تعریف شده‌اند، نه در
مخزن: `docker-compose.base44.yml` و `wp-setup.sh` در مخزن پیکربندی محیط.

## ۴. تصمیم‌های پیاده‌سازی

- **قالب پایه:** Twenty Twenty-Five (قالب بلوکی همراه هسته) تا Child Theme بدون
  وابستگی به قالب تجاری و بدون قفل شدن ساخته شود.
- **صفحه‌سازی:** Gutenberg با بلاک‌های هسته + شورت‌کدهای ووکامرس؛ Elementor
  استفاده نمی‌شود (تصمیم فاز ۱).
- **دیزاین سیستم:** `tokens.css` و `components.css` فاز ۲ بدون تغییر کپی شده‌اند؛
  هیچ رنگ خامی در `theme.css` نوشته نشده و همه از `var(--ab-*)` می‌آید.
- **شناسنامهٔ گیاه:** جدول اختصاصی `wp_ab_plants` با کلید یکتا روی `product_id`
  (طبق فاز ۱، بدون کلید خارجی به `wp_posts` تا با تغییر پیشوند نصب نشکند).
- **واحد پول:** `IRT` با نماد «تومان» و بدون اعشار، تا قیمت‌ها همان اعداد کاتالوگ
  فاز ۳ باشند.
- **ایمپورت:** SKU هر محصول همان `id` کاتالوگ است؛ اجرای دوباره به‌روزرسانی
  می‌کند و رکورد تکراری نمی‌سازد. تصاویر فقط اگر محصول تصویر نداشته باشد اضافه
  می‌شوند.

## ۵. روش اجرا و تست

در محیط Base44 سرویس `wp-setup` خودکار اجرا می‌شود. اجرای دستی:

```bash
docker compose -p app -f "$BASE44_CONFIG_ROOT/docker-compose.base44.yml" up -d db wp wp-setup
docker compose -p app -f "$BASE44_CONFIG_ROOT/docker-compose.base44.yml" exec -T wp wp --allow-root plugin list
```

سایت روی پورت ۸۰۸۰ بالا می‌آید (نمونهٔ استاتیک فاز ۳ روی ۳۰۰۰ می‌ماند). ورود مدیر:
`admin` / `attar-admin-1404` در `/wp-admin/` — فقط محیط توسعه.

۱. `/` باید قهرمان فارسی، ۶ دسته و ۸ محصول برگزیده را نشان دهد.
۲. `/shop/` باید ۱۲ محصول در هر صفحه با قیمت تومان نشان دهد.
۳. `/product/saffron/` باید گالری، قیمت ۲۸۵٬۰۰۰ تومان و باکس «شناسنامهٔ گیاه»
   (نام علمی، خاستگاه، بخش مصرفی، روش مصرف، نگهداری، هشدارها) را نشان دهد.
۴. `wp attar import` دوباره: باید «۰ محصول جدید، ۴۹ به‌روزشده» بدهد.

## ۶. محدودیت‌های شناخته‌شده (فازهای بعد)

- محصولات متغیر (اندازه‌ها) هنوز ساخته نشده‌اند؛ قیمت پایه = اندازهٔ اول کاتالوگ.
- باشگاه مشتریان، علاقه‌مندی، پیامک، درگاه زرین‌پال و جست‌وجوی زنده در فازهای ۵–۶.
- ۴۳ محصول بدون تصویر تأییدشده با برچسب «به‌زودی» ایمپورت شده‌اند (طبق استاندارد
  تصویر، تصویر ساختگی ساخته نمی‌شود).
- بستهٔ ترجمهٔ فارسی هسته و ووکامرس در اسکریپت نصب به‌صورت zip دستی نصب می‌شود،
  چون `wp language` در این محیط به API باینری وردپرس دسترسی ندارد.
