# ATTAR-BALAD-IMAGE-LIBRARY

کتابخانه تصاویر عطار بلد. هر تصویر فقط یک‌بار اینجا ذخیره می‌شود و سایت و مستندات از همین مسیرها استفاده می‌کنند.

```
image-library/
├── 01-MEDICINAL-HERBS/      گیاهان دارویی (اسطوخودوس، آویشن، بابونه…)
├── 02-SPICES/               ادویه‌جات (زعفران، دارچین، زردچوبه…)
├── 03-HERBAL-TEAS/          دمنوش‌ها (گل محمدی، چای سبز، چای ترش…)
├── 04-OILS-EXTRACTS/        عرقیات و روغن‌ها (گلاب، روغن‌های گیاهی)
├── 05-SEEDS-GRAINS/         بذر و دانه (خاکشیر، کنجد، تخم کتان…)
├── 06-DRIED-FRUITS-NUTS/    خشکبار (بادام، پسته، زرشک)
├── 07-GUMS-RESINS/          صمغ‌ها و فرآورده‌های طبیعی
├── PRODUCT-DATABASE/        products.json – فهرست کاتالوگ و اتصال هر محصول به تصویرش
├── LICENSE-RECORDS/         مجوز و منبع هر تصویر
├── THUMBNAILS/              تصاویر کوچک و کانتکت‌شیت کاتالوگ
└── APPROVED-IMAGES/         فقط تصاویری که چک‌لیست استاندارد را پاس کرده‌اند
```

## قاعده تولید تصویر

پیش از افزودن هر تصویر جدید، [IMAGE-STANDARD.md](IMAGE-STANDARD.md) را بخوانید: گیاه خشک داخل ظرف مسی، ظاهر طبیعی و فله‌ای با ساقه و برگ و گل خشک، تطبیق با نمونه واقعی مشکستان و عطارک؛ و لوگو، قاب، رنگ‌ها، معماری تاریخی، نورپردازی و نوشته‌ها بدون تغییر.

## چرخه کار

1. تصویر جدید در پوشه دسته خودش قرار می‌گیرد.
2. با چک‌لیست استاندارد بازبینی می‌شود.
3. مسیر تصویر در `PRODUCT-DATABASE/products.json` ثبت می‌شود (`image_status: approved`).
4. صفحه سایت از همان مسیر استفاده می‌کند.
